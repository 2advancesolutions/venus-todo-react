# Venus Todo React

A beautiful, drag-and-drop todo app built with React, TypeScript, and Tailwind CSS.

## Features

- ✅ Create, update, and delete todos
- ✅ Drag and drop to move todos between active and completed sections
- ✅ Reorder todos within each section
- ✅ Beautiful gradient background with glassmorphism effects
- ✅ Responsive design
- ✅ Edit todos inline with keyboard shortcuts

## Tech Stack

- React 18 with TypeScript
- Vite for fast development
- Tailwind CSS for styling
- @dnd-kit for drag and drop functionality

## Getting Started

1. Install dependencies:
```bash
npm install
```

2. Start the development server:
```bash
npm run dev
```

3. Open your browser to `http://localhost:5173`

## Usage

- **Add tasks**: Type in the input field and press Enter or click "Add"
- **Edit tasks**: Click the pencil icon, edit the text, then press Enter to save or Escape to cancel
- **Delete tasks**: Click the trash icon
- **Drag and drop**: Drag tasks between the "Active Tasks" and "Completed Tasks" sections to change their status
- **Reorder**: Drag tasks within each section to reorder them

## Build for Production

```bash
npm run build
```

The built files will be in the `dist` directory.
