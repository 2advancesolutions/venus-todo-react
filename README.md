# Venus Todo - Modern React 19 Todo App

A sleek, modern todo application built with React 19, TypeScript, and Tailwind CSS.

## ✨ Features

- **Add Todos**: Create new tasks with a clean input interface
- **Edit Todos**: Click any todo text to edit it inline
- **Delete Todos**: Remove tasks with a single click
- **Toggle Complete**: Mark tasks as complete/incomplete
- **Responsive Design**: Works perfectly on desktop and mobile
- **Modern UI**: Clean, minimalist design with smooth animations
- **Real-time Stats**: See your todo count and completion status

## 🚀 Tech Stack

- **React 19** - Latest React with new hooks and features
- **TypeScript** - Full type safety
- **Vite** - Lightning-fast build tool
- **Tailwind CSS** - Utility-first CSS framework
- **PostCSS** - CSS processing

## 📦 Installation

```bash
# Clone the repository
git clone <repository-url>
cd venus-todo-react

# Install dependencies
npm install

# Start the development server
npm run dev
```

## 🎯 Usage

1. **Add a Todo**: Type your task in the input field and press Enter or click "Add"
2. **Edit a Todo**: Click on any todo text to edit it inline, then press Enter or click "Save"
3. **Toggle Complete**: Click the checkbox to mark a todo as complete/incomplete
4. **Delete a Todo**: Hover over any todo and click the "Delete" button

## 🛠️ Development

```bash
# Development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview

# Type checking
npm run type-check
```
