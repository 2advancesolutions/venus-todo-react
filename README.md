# Venus Todo React

A lightweight todo list application built with React and Vite. Users can add, update, complete, and delete tasks. Todos persist locally in the browser via Local Storage.

## 🚀 Getting Started

```bash
npm install
npm run dev
```

Then open the provided URL (defaults to [http://localhost:5173](http://localhost:5173)).

## 🛠 Features

- Create new todo items
- Toggle task completion state
- Edit existing todos inline
- Delete todos individually
- Local storage persistence
