# Venus Todo React

A focused React + Vite Todo application that supports adding, updating, completing, filtering, and deleting tasks. Todos are stored locally in the browser for a seamless demo experience.

## Getting Started

```bash
# Install dependencies
npm install

# Start the development server
npm run dev

# Build for production
npm run build

# Preview the production build
npm run preview
```

The application is served at the URL reported in the terminal (typically http://localhost:5173).

## Features

- Create new todo items with inline validation
- Edit existing items using an inline form
- Mark tasks as complete or active and filter by status
- Delete individual tasks or clear all completed tasks
- Persist todos using `localStorage`
- Responsive layout with accessible controls
